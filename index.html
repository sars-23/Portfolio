Arbor — Programming Language Interpreter

Private Academic Repo

A custom tree-walk interpreter for a dynamically typed programming language written completely from scratch in Java. Arbor features a handwritten lexical scanner that converts source into tokens, a recursive-descent parser that constructs an Abstract Syntax Tree (AST), and an execution engine implementing the Visitor pattern to handle lexical scope, environments, and first-class closures.

Java Lexer & Parser AST Visitor Pattern Lexical Closures Runtime Environment
