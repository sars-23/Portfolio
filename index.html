About Me

Curious about how code actually executes.

A genuine passion for programming language implementation, clean abstractions, and backend systems.

Hey there! I'm Saransh Singh, a Computer Science undergraduate at JECRC University in Jaipur. While modern development often abstracts away the lower layers of execution, I've always been fascinated by what happens between writing a line of code and the machine executing it.

That curiosity led me to build Arbor, a complete dynamically typed tree-walk interpreter written from scratch in Java — featuring a handwritten lexical scanner, recursive-descent parser, Abstract Syntax Tree (AST), and first-class closures.

It also inspired Project Apricorn, where I tackled container isolation, asynchronous dispatch, and attempt analytics to build a coding platform centered around developer learning patterns rather than binary pass/fail verdicts.

I believe great software engineering is about clean abstractions, honest trade-offs, solid testing, and code that is a pleasure to read and maintain. I'm actively seeking software engineering internships and junior developer roles where I can contribute meaningfully and grow.
